# 蓝脑星球培训讲师工作台

内部团队使用的讲师 IP 诊断、受众判断、内容创作与稿件诊断工作台。

## 内部使用方式

1. 管理员在托管环境中设置共同入口密码 `INTERNAL_ACCESS_CODE`。
2. 团队成员使用同一个入口密码进入工作台；老师本人不需要注册或登录。
3. 讲师卡、对话、IP 判断、内容路径、风格卡和草稿统一保存到团队资料库。

## 数据与更新

页面更新不会清空 D1 中的讲师资料。程序代码、数据库迁移和实际讲师资料彼此分开：发布新页面只替换程序；已保存的资料继续保留。

当两个人同时编辑同一份资料时，较旧的页面不会静默覆盖最新内容。系统会提示刷新最新资料，并保留当前页面的修改，让使用者自行决定如何合并。

不要把共同入口密码、会话信息或真实老师对话写进 GitHub、示例文件或聊天记录。

## 后续升级

当前版本适合前期一两位内部人员共同使用。团队扩大后，可以在不迁移讲师资料的前提下增加个人账号、角色权限和操作记录。
