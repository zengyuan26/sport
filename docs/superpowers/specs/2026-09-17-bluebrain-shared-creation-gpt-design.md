# 蓝脑星球培训讲师工作台：共享创作 GPT 交接设计

## 已确定的选择

内部讲师已具备 ChatGPT 使用条件。第一期不在工作台里接入模型 API，而是把真正的联网研究与对话式创作交给一套共享的「蓝脑星球创作 GPT」。工作台保留讲师画像、受众、商业路径与创作资产；创作 GPT 保留方法论并完成对话、检索、选题和出稿。

这不是在工作台里再实现一个简化版聊天机器人。跳转是有意的边界：不使用独立 API 成本，也不尝试读取每位内部成员的个人 ChatGPT 会话。

## 两个产品各自负责什么

### 工作台

- 从当前讲师的 IP 诊断中读取身份信号、受众、产品和变现路径。
- 发起、暂存与归档一条创作任务。
- 让使用者选择素材入口：新闻 / 链接、洗稿、原创想法。
- 把讲师上下文与输入素材生成一段可直接交给创作 GPT 的任务说明。
- 记录创作任务的状态，以及从 GPT 回填的选题、内容形态、写法和成稿。

### 蓝脑星球创作 GPT

- 以现有「创作」对话中沉淀的方法为系统方法，而不是让讲师自行提问。
- 围绕用户提供的新闻、链接、参考稿或概念补找可用素材。
- 按「素材 / 概念 → 角度 → 选题 → 内容目的 → 情绪结构 → 内容形态 → 写法 → 成稿」推进。
- 先给可选角度，再让用户决定；不直接把每条素材硬写成招生文。
- 明确标注每个选题的用途：身份信号强化、商业目的强化、双重强化，或不建议进入当前主线。
- 需要事实或研究结论时给出来源；无法确认时说清边界，不编造研究、人物或数据。

## 工作台的内容创作页

内容创作页调整为一屏的「发起创作任务」而不是当前的本地生成器。

1. 顶部显示当前老师和本次创作会自动携带的背景：主身份、可服务人群、主产品。
2. 三张入口卡：
   - 新闻 / 链接：粘贴新闻链接、热点或原始素材。
   - 洗稿：粘贴参考图文、长文或口播稿，提取新观点与可重写方向。
   - 原创想法：写下一个概念、观察或想聊的事；可选本次优先说给谁。
3. 点击「带着这条任务去创作」后：
   - 工作台生成并复制完整任务说明；
   - 在新标签打开共享 GPT；
   - 页面显示「任务已复制，进入 GPT 后粘贴即可开始」。
4. 回来后点击「回填创作结果」；先保留最小字段：最终选题、内容目的、内容形态、使用方法、最终稿。后续再扩展为多次创作记录。

共享 GPT 的地址保存在页面配置中。链接尚未创建时，按钮不可假装可以跳转，而是清楚提示管理员完成创作 GPT 的发布。

## 三类输入的共同路径

所有入口都遵守同一条判断链：

```
输入素材或概念
→ 补找 / 筛选主题素材
→ 找到可讲的角度
→ 定选题与标题方向
→ 标注身份、商业或双重目的
→ 苦 → 欲 → 怕 → 罪 → 事 → 物 → 框 → 心 → 行 → 留
→ 选择内容形态与固定方法
→ 成稿
```

新闻和概念不应变成表层复述。创作 GPT 先检查：受众面对的损失是否重要且难以逆转、讲师是否有正当的进入位置、哪些事实需要来源、哪些结论不能过度推断。

## 固定写法与内容形态

写法不允许各位讲师临时新增，改由共享 GPT 固定提供。

- 长文 / 口播
  - 小德写法：商业案例 / 现实困惑 → 判断链 → 类比与机制 → 行动意义。
  - 朱莉娅写法：反常识命题 → 现象与人物 / 资料 → 重估价值 → 有力度的收束。涉及事实、研究、历史案例时必须核实。
- 图文
  - 资料与结构：资料压缩、知识地图、外部素材转译。
  - 判断与行动：实物比较、决策代办、诊断处方、模板交付。
  - 观点与叙事：利益冲突、热点事故、价值观演练。
  - 体验与证明：体验种草、改造见证、实验数据、个人经历。

「推荐」只能是一枚建议标记，最终写法由老师选择。

## 共享 GPT 的交接格式

工作台复制的任务说明包含：

- 当前老师与主身份；
- 本次可优先服务的受众、产品和商业路径；
- 输入类别与原始素材；
- 原创入口下的可选受众；
- 明确要求创作 GPT 先研究和给出 3–5 张角度卡，不直接出完整稿；
- 角度卡需要写清：受众张力、讲师进入位置、新判断、建议选题、内容目的、事实边界和来源。

回填说明要求 GPT 最后输出一个简洁的「工作台回填包」，避免使用者从长对话中重新整理。

## 访问与数据边界

- 工作台内仍用现有共同入口密码与共享工作区保存资料。
- 创作 GPT 的访问范围应设置为内部成员可访问；不能在工作台或 Git 仓库保存用户的 ChatGPT 凭据。
- 工作台只复制任务说明，不把它自动发送到个人 ChatGPT 对话。
- 工作台更新不覆盖既有讲师资料；新增创作任务字段采用可选字段，以兼容现有资料。

## 第一版验收

- 内容创作页不再本地虚构联网分析或生成稿件。
- 三种素材入口均能生成带当前讲师上下文的任务说明。
- 任务说明可一键复制，并在有已发布共享 GPT 地址时打开它。
- 回填结果会随团队工作区保存，刷新与多人共享机制继续有效。
- 不存在「新增参考风格」入口；写法和图文类型由共享 GPT 的固定方法库提供。
