# 蓝脑星球创作助手（内部版）

这是给 Chrome / Edge 使用的浏览器扩展，不调用 OpenAI API。

它只做三件事：

1. 在讲师工作台收到一次明确的“带去创作”请求；
2. 把这一次的任务简报暂存在该浏览器本地，并打开 `chatgpt.com`；
3. 由使用者点击“填入对话框”后，把简报填进 ChatGPT 的新对话输入框。扩展不会自动发送，也不会读取既有聊天记录。

## 内部安装

1. 使用 Chrome 或 Edge 打开扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本文件夹 `browser-extension`。
5. 登录讲师工作台后，内容创作页会显示“蓝脑创作助手已就绪”。

## 边界

- 扩展只支持工作台域名和 `chatgpt.com`，没有其它网站权限。
- 任务只保存在当前浏览器，直到使用者点“填入对话框”或被下一条任务替换。
- ChatGPT 网页界面若改动，输入框定位可能需要升级扩展；工作台仍保留“复制任务说明”的手动兜底。
